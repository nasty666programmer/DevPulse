# DevPulse — Дизайн-спецификация веб-интерфейса

Версия: 1.0
Дата: 2026-08-17
Статус: для реализации фронтенд-агентом (React)

## 0. Принципы

DevPulse — это личный дайджест для чтения, а не админ-панель и не публичный SaaS-продукт.
Референсы по тону: Pocket, Reeder, Node Weekly / рассылки-дайджесты.

1. **Контент важнее хрома.** Максимум пространства — тексту статей, минимум — декоративным элементам.
2. **Одна колонка.** Это не multi-column дашборд. Лента — вертикальный список карточек, отцентрованный,
   с шириной, комфортной для чтения (не на всю ширину экрана даже на десктопе).
3. **Тёмная тема — основная/дефолтная.** Светлая — равноценная альтернатива, не "техдолг".
4. **Минимум цвета.** Один акцентный цвет используется последовательно (ссылки, кнопка обновления,
   фокус-состояния). Никаких градиентов, никаких декоративных иконок ради иконок.
5. **Никаких внешних зависимостей.** Системные шрифты, никаких иконок из CDN — SVG-иконки инлайн
   (простые, line-style, из 1-2 svg-path, без сторонних иконочных библиотек типа FontAwesome).

## 2. Типографика

Без веб-шрифтов из интернета — только системные стеки, чтобы страница открывалась офлайн.

```css
--font-ui:   system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
--font-read: Georgia, "Iowan Old Style", "Palatino Linotype", "Book Antiqua", ui-serif, serif;
--font-mono: ui-monospace, "SF Mono", "Cascadia Code", "Consolas", "Roboto Mono", monospace;
```

Логика смешения шрифтов:
- **`--font-ui`** — вся "хром"-типографика: шапка, кнопки, заголовки карточек в ленте, лейблы.
- **`--font-read`** — только тело **раскрытой статьи** (длинный текст читается легче с засечками).
- **`--font-mono`** — мета-данные: домен источника, timestamp, счётчики ("5 мин чтения").

### 2.1 Шкала размеров

| Роль | Размер / line-height | Шрифт | Насыщенность | Токен цвета |
|---|---|---|---|---|
| Product title (шапка, "DevPulse") | 18px / 1.2 | `--font-ui` | 700 | `--text-primary` |
| Заголовок карточки (H2, в ленте) | 19px / 1.35 | `--font-ui` | 600 | `--text-primary` |
| Заголовок раскрытой статьи (H1) | 26px / 1.3 | `--font-ui` | 700 | `--text-primary` |
| Excerpt (свёрнутая карточка) | 15px / 1.55 | `--font-ui` | 400 | `--text-secondary` |
| Body раскрытой статьи | 17px / 1.7 | `--font-read` | 400 | `--text-secondary` |
| Meta (источник · дата · время чтения) | 12.5px / 1.4, letter-spacing 0.01em | `--font-mono` | 500 | `--text-meta` |
| Кнопки | 14px / 1 | `--font-ui` | 600 | — |

Максимальная ширина строки текста статьи: `65–72ch` — достигается за счёт общей ширины контента
(см. §3), а не отдельного column-width на тексте.

## 3. Сетка, spacing, breakpoints

### 3.1 Шкала отступов (4px база)

```
--space-1: 4px
--space-2: 8px
--space-3: 12px
--space-4: 16px
--space-5: 20px
--space-6: 24px
--space-7: 32px
--space-8: 48px
--space-9: 64px
```

### 3.2 Layout

- Контент — **одна центрированная колонка**, `max-width: 680px`, `margin: 0 auto`.
- Внешние отступы страницы: `padding-inline: var(--space-4)` на мобильном, `var(--space-6)` на десктопе.
- Шапка — `position: sticky; top: 0`, растянута на всю ширину, внутренний контент ограничен теми же 680px
  (плюс padding), чтобы кнопка "Обновить" визуально выравнивалась с карточками.
- Вертикальный зазор между карточками в ленте: `var(--space-4)` (16px).
- Внутренние отступы карточки: `var(--space-5)` (20px) на мобильном, `var(--space-6)` (24px) на десктопе.

### 3.3 Breakpoints

| Имя | Диапазон | Поведение |
|---|---|---|
| Mobile | `< 640px` | padding-inline 16px, заголовок карточки 18px, кнопка "Обновить" — компактная (иконка + короткий текст либо только иконка при < 380px) |
| Tablet / Desktop | `≥ 640px` | max-width 680px вступает в силу, стандартные размеры типографики из §2 |
| Wide (опционально) | `≥ 1024px` | контент остаётся 680px и центрируется — НЕ растягивать в multi-column грид. Дайджест — линейный поток чтения. |

Никакой адаптивной "карточной сетки в 2-3 колонки" — сознательное решение, чтобы сохранить
ритм чтения дайджеста (как у email-рассылки), а не превращать в Pinterest-подобную ленту.

## 4. Компоненты

### 4.1 Шапка (Header)

- Высота: 60px (мобильный) / 68px (десктоп).
- Фон: `--bg-elevated`, нижняя граница `1px solid var(--border)`.
- При скролле — остаётся `sticky top:0`, тень не добавляется (граница и так отделяет), допускается
  лёгкое усиление тени на скролле: `box-shadow: 0 1px 0 var(--border)` (уже есть от border, поэтому
  доп. тень не обязательна — держим плоско).
- Состав (flex, space-between):
  - Слева: имя продукта `DevPulse` + маленькая точка-индикатор пульса (8px circle, `--accent`,
    статична, не анимирована — просто акцент бренда) — H в `--font-ui` 18px/700.
  - Справа: строка "обновлено 5 минут назад" (`--text-meta`, `--font-mono`, 12px, скрывается на
    экранах < 380px) + кнопка "Обновить дайджест".

### 4.2 Кнопка "Обновить дайджест" (Primary Button)

- Форма: `border-radius: 8px`, `padding: 9px 16px`, `font: 600 14px var(--font-ui)`.
- Фон: `--accent`; текст: `--accent-text-on`; без border, без тени.
- Hover: фон → `--accent-hover`, `cursor: pointer`.
- Focus-visible: `outline: 2px solid var(--accent); outline-offset: 2px`.
- Active/loading: иконка-стрелка (простой inline SVG ↻) получает `animation: spin 0.8s linear infinite`,
  текст меняется на "Обновляем…", кнопка `disabled` (opacity 0.7, cursor default).
- Иконка слева от текста, `gap: 8px`, размер иконки 16px.
- Вторичная/ghost-версия (если понадобится, напр. "Показать оригинал"): прозрачный фон,
  `border: 1px solid var(--border-strong)`, текст `--text-primary`, hover фон `--surface-hover`.

### 4.3 Карточка статьи (Article Card) — свёрнутое состояние

- Контейнер: `background: var(--surface)`, `border: 1px solid var(--border)`,
  `border-radius: 12px`, `padding: 20px` (24px на десктопе).
- Hover (весь блок кликабелен как область раскрытия, кроме ссылки "оригинал"):
  `background: var(--surface-hover)`, `border-color: var(--border-strong)`,
  `transition: background 0.15s ease, border-color 0.15s ease` (никаких transform/scale — это не
  карточка-кнопка маркетингового сайта).
- Внутренняя структура (vertical stack, gap `var(--space-2)` между мета/заголовком, `var(--space-3)`
  перед excerpt, `var(--space-4)` перед футером карточки):
  1. **Meta-строка**: `источник.домен · 17 авг, 08:14 · 4 мин чтения` — `--font-mono` 12.5px `--text-meta`,
     разделитель `·` с пробелами по бокам.
  2. **Заголовок** (H2): `--font-ui` 19px/600 `--text-primary`, `line-clamp: 3` на мобильном.
  3. **Excerpt**: `--font-ui` 15px/1.55 `--text-secondary`, `line-clamp: 3`, обрезка с `…`.
  4. **Футер карточки** (flex, space-between, margin-top `var(--space-4)`):
     - Слева: текстовая кнопка "Читать дальше" (не filled-button — текст цвета `--accent`,
       `font: 600 14px var(--font-ui)`, hover — подчёркивание) — разворачивает карточку inline.
     - Справа: ссылка-иконка "Открыть оригинал ↗" (`--text-meta`, hover → `--text-primary`),
       ведёт на исходный URL в новой вкладке.
- Никаких обложек/превью-картинок в macro-версии 1.0 (контент текстовый, источники — RSS без гарантии
  качественных изображений) — оставляем чисто текстовый, "read-first" вид.

### 4.4 Раскрытая карточка (Expanded state)

- Та же карточка, `border-color` меняется на `--accent` с 30% opacity (напр. `color-mix` или
  заранее посчитанный полупрозрачный hex) ЛИБО остаётся `--border-strong` — держим сдержанно,
  не подсвечивать слишком ярко.
- Заголовок статьи увеличивается до H1 26px/700 (или остаётся H2 19px — на усмотрение фронтенда,
  главное — визуально сообщить "это теперь фокус экрана": доп. `margin-bottom: var(--space-4)`).
- Разделитель `1px solid var(--border)` между meta+заголовком и полным текстом, `margin-block: var(--space-4)`.
- Полный текст статьи — `--font-read` (Georgia-стек), 17px/1.7, `--text-secondary`, абзацы с
  `margin-bottom: var(--space-4)`, параграфы `max-width: 68ch` (естественно ограничено 680px контейнера).
- Футер раскрытой карточки: кнопка "Свернуть ▲" (тот же текстовый стиль, что и "Читать дальше") +
  ссылка "Открыть оригинал ↗" сохраняется.
- Анимация раскрытия: `max-height`/`opacity` transition 0.2s ease НЕ обязательна технически, но
  желательна для ощущения "мягкости"; допустимо и мгновенное раскрытие без анимации — не критично.

### 4.5 Пустое состояние (Empty state)

- Показывается по центру, вертикально в области ленты, `padding-block: var(--space-9)` (64px+).
- Простая inline-SVG иконка (напр. контур "лотка"/tray или "облако", 40×40px, `stroke: var(--text-disabled)`,
  `stroke-width: 1.5`, без заливки — линейный минималистичный стиль).
- Заголовок: "Новостей пока нет" — 17px/600 `--text-primary`, margin-top `var(--space-4)` после иконки.
- Подпись: "Нажмите «Обновить дайджест», чтобы собрать свежие статьи из источников." — 14px `--text-meta`,
  max-width 320px, text-align center, margin-top `var(--space-2)`.
- Опционально кнопка-дубликат "Обновить дайджест" под подписью (та же Primary Button), margin-top `var(--space-5)`.

### 4.6 Состояние загрузки (Skeleton)

- 3 плейсхолдер-карточки одинаковой структуры с реальной карточкой (те же padding/radius/border),
  внутри — прямоугольники-заглушки:
  - meta-строка: полоса 120×10px, `border-radius: 4px`
  - заголовок: 2 полосы 90%×16px и 60%×16px, gap 8px
  - excerpt: 3 полосы 100%/100%/70% × 12px, gap 6px
- Цвет заглушек: `--skeleton-base`, поверх — анимированный градиентный блик `--skeleton-shine`,
  `background: linear-gradient(90deg, var(--skeleton-base) 25%, var(--skeleton-shine) 50%, var(--skeleton-base) 75%)`,
  `background-size: 200% 100%`, `animation: shimmer 1.6s ease-in-out infinite`.
- Уважение `prefers-reduced-motion: reduce` — если включено, анимация отключается, остаётся статичный
  `--skeleton-base` фон.

### 4.7 Состояние ошибки (Backend недоступен)

- Плашка на месте ленты (не toast/notification — постоянный блок, т.к. это единственный контент экрана):
  `background: var(--danger-bg)`, `border: 1px solid var(--danger)` (тонкая, 1px), `border-radius: 12px`,
  `padding: var(--space-5)`.
- Иконка предупреждения (inline SVG, круг с "!", 20px, `stroke: var(--danger)`) + заголовок
  "Не удалось загрузить дайджест" (`--text-primary`, 15px/600) в одной строке (gap 10px).
- Подпись с текстом ошибки/причиной: "Сервер недоступен. Проверьте, что backend запущен на порту 4000."
  — `--text-meta`/`--danger` (можно `--text-secondary`), 14px, margin-top `var(--space-2)`.
- Кнопка "Повторить" (ghost-стиль из §4.2), margin-top `var(--space-4)`.

### 4.8 Переключатель темы (Theme toggle)

- Небольшая icon-button в шапке (солнце/луна, inline SVG 18px), справа от кнопки "Обновить" либо слева
  от неё. `width/height: 36px`, `border-radius: 8px`, `background: transparent`, hover → `--surface-hover`.
- Не входит в изначальный список экранов ТЗ явно, но нужен, т.к. поддерживаются обе темы — реализован
  и в mockup.html (переключение класса на `<html>`/`<body>`), фронтенд-агент может сохранить выбор в
  `localStorage`.

## 5. Радиусы, тени, границы — сводная шкала

```
--radius-sm: 6px   /* мелкие бейджи, скелетон-полосы */
--radius-md: 8px   /* кнопки, icon-button */
--radius-lg: 12px  /* карточки, плашка ошибки, пустое состояние (если в рамке) */
```

- Тени практически не используются (плоский, контентный дизайн, границы вместо теней — характерно
  для reading-app эстетики). Единственное допустимое исключение — очень лёгкая тень под sticky-шапкой
  при скролле, если дизайнер/фронтенд сочтёт нужным добавить глубину:
  `box-shadow: 0 4px 12px -8px rgba(0,0,0,0.35)` (тёмная тема) /
  `0 4px 12px -8px rgba(20,15,10,0.12)` (светлая тема) — опционально, не обязательно.
- Border width везде `1px`, кроме focus-ring (`2px solid var(--accent)`, `outline-offset: 2px`).

---

## 6. Иконки

Все иконки — инлайн SVG, `stroke`-based (line icons), `stroke-width: 1.5–2`, без заливки, размер
16–20px в зависимости от контекста, наследуют `currentColor`. Требуемый минимальный набор:
обновить/refresh (↻), внешняя ссылка (↗), шеврон/раскрытие (▾/▴ либо +/−), солнце, луна,
предупреждение (! в круге), пустой лоток/облако для empty state.

---

## 7. Доступность (кратко)

- Все интерактивные элементы — реальные `<button>`/`<a>`, фокус видим (`:focus-visible`, accent outline).
- Контраст текста проверен для обеих тем (см. §1).
- `prefers-reduced-motion` уважается для skeleton-shimmer и spin-анимации кнопки обновления.
- Раскрытие карточки — доступно с клавиатуры (Enter/Space на кнопке "Читать дальше"), `aria-expanded`
  на кнопке, `aria-controls` указывает на блок полного текста.

## 8. Что сознательно НЕ включено в v1

- Многоколоночная сетка карточек.
- Изображения-превью статей.
- Теги/категории, поиск, фильтры по источнику — не запрошены, не проектировались.
- Пагинация/infinite scroll — за пределами ТЗ; лента предполагается разумно короткой (один "утренний" батч).

Файл `mockup.html` в этой же папке — статическая демонстрация верстки для обеих тем со всеми
состояниями из этого документа (шапка, 4-5 карточек, одна раскрытая карточка, пустое состояние,
skeleton, ошибка — доступны через переключатель темы и статичные блоки на одной странице).
